# BioChem Lab 🧬
Bilingual (EN/AR) interactive biochemistry course: lectures + practice exam.
Pure HTML, CSS and JavaScript (no build step).

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a new repository and upload all files (keep the folder structure).
2. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save.
3. Your site appears at `https://<username>.github.io/<repo>/` after a minute.

## Edit content
- Lectures and exam questions: `js/data.js`
- Look and feel: `css/style.css`
- Behavior and widgets: `js/app.js`
